# intelligrate 0.1.2

Usability release for config-driven CLI runs from pip installs.

Install from PyPI after release:

```bash
pip install intelligrate==0.1.2
```

## Highlights

- Added installed config templates for extrapolate and subset workflows.
- Added CLI template writers:
  - `intelligrate extrapolate write-config --out configs/default.yaml`
  - `intelligrate subset write-configs --out-dir configs`
- Expanded `train` and `fixed-param-sweep` help text to show how to start from an editable config.
- Updated release testing instructions for the hierarchical CLI and template commands.

## Notes

- `0.1.2` is the next package version because `0.1.1` was already uploaded to TestPyPI.
- Example notebooks and datasets remain in the GitHub repository.

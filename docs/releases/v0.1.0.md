# intelligrate 0.1.0

First public release of `intelligrate`.

Install from PyPI:

```bash
pip install intelligrate
```

Install with optional map dependencies for geographic subset plots:

```bash
pip install "intelligrate[maps]"
```

## Included

- `intelligrate.extrapolate` workflow for fitting paired X/Y data and predicting target profiles for broader datasets.
- `intelligrate.subset` workflow for diversity-aware and metadata-aware sample subsetting.
- Installed CLI commands:
  - `intelligrate-extrapolate-train`
  - `intelligrate-extrapolate-full-fit`
  - `intelligrate-extrapolate-full-predict`
  - `intelligrate-extrapolate-fixed-param-sweep`
  - `intelligrate-subset`
- BSD 3-Clause license and package metadata for PyPI.
- CI covering Python 3.10, 3.11, and 3.12.
- Unit tests for package behavior and release hygiene.
- GitHub repository tutorials, notebooks, and example data.

## Notes

- The PyPI package contains the installable library only.
- Tutorials, notebooks, and example datasets are available in the GitHub repository.
- Supported Python versions for this release: `>=3.10,<3.13`.

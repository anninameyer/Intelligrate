# intelligrate 0.1.3

Notebook usability release based on TestPyPI tutorial testing.

Install from PyPI after release:

```bash
pip install intelligrate==0.1.3
```

## Highlights

- Fixed Matplotlib colormap usage in subset notebooks for newer Matplotlib versions.
- Updated pathway aggregation code in extrapolate notebooks for newer Pandas versions.
- Added `seaborn` and `statsmodels` as installed dependencies so tutorial plotting and FDR-correction cells work after package install.
- Clarified that PICRUSt2 predictions and KO/pathway superclass mappings are optional comparison and visualization inputs, not required for model training or prediction.

## Notes

- Use `intelligrate extrapolate write-config --out configs/default.yaml` for editable extrapolate YAML defaults.
- Use `intelligrate subset write-configs --out-dir configs` for editable subset YAML defaults.

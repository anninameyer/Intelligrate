# intelligrate 0.1.1

Usability release focused on installation, tutorials, notebooks, and CLI help.

Install from PyPI:

```bash
pip install intelligrate==0.1.1
```

## Highlights

- Added a top-level hierarchical CLI:
  - `intelligrate --help`
  - `intelligrate subset --help`
  - `intelligrate extrapolate --help`
- Added action-level subset commands:
  - `intelligrate subset distance`
  - `intelligrate subset suggest-k`
  - `intelligrate subset kmedoids`
  - `intelligrate subset ga`
- Improved extrapolate CLI help for:
  - `intelligrate extrapolate train`
  - `intelligrate extrapolate fixed-param-sweep`
  - `intelligrate extrapolate full-fit`
  - `intelligrate extrapolate full-predict`
- Updated notebooks to work with `pip install intelligrate` and separately downloaded GitHub example data.
- Clarified cross-platform install instructions for macOS, Linux, and Windows.
- Added install verification commands and clearer notebook/data folder layout instructions.

## Notes

- The PyPI package contains the installable library only.
- Tutorials, notebooks, and example datasets remain in the GitHub repository.
- Supported Python versions: `>=3.10,<3.13`.
